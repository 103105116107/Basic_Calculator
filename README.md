A simple Android application designed to perform basic arithmetic operations. This project focuses on a clean user interface and fundamental mathematical logic implementation in a mobile environment.

Features
Addition Logic: Core functionality to perform addition between multiple inputs.

Result Display: Real-time or triggered display of calculation results.

Clear Functionality: Single-tap feature to reset all entries and start new calculations.

Minimalist UI: Uncluttered design focused on usability and efficiency.

Technical Details
The project is built using standard Android development tools:

Platform: Android

Build System: Gradle (Kotlin DSL)

Project Structure: Standard Android app architecture including manifest, resources, and java/kotlin source sets.

Installation and Setup
For Developers
Clone the repository:

Bash

git clone https://github.com/103105116107/Basic_Calculator.git
cd Basic_Calculator
Open in Android Studio:

Launch Android Studio.

Select "Open an Existing Project".

Navigate to the cloned directory and select the build.gradle.kts file.

Run the Application:

Connect an Android device or start an emulator.

Click the "Run" button in Android Studio.
